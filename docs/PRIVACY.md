# 数据与隐私

灵墨阅读在应用本地空间保存书籍、进度、札记、书志和拾墨。卸载应用可能删除这些数据，请按需导出备份。

## AI 请求

AI 使用你配置的 HTTPS 兼容接口。对话可能发送问题、引用、阅读范围内的相关正文和必要历史。目录优化和书志整理按任务发送正文片段。

API Key 经 Android Keystore 加密保存在设备上。备份排除密钥。导入的模型连接获得新 ID，使用前重新填写密钥。

应用关闭模型请求的自动重定向。所填接口的服务条款、数据处理与费用以服务商说明为准。

## OCR

拾墨使用 Google ML Kit 中文识别，图片和识别结果在设备上处理。

OCR 在首次识字时初始化，基础阅读和浏览摘抄使用本地数据。启用 OCR 后，Google ML Kit 可能联系其服务器获取兼容信息、修复或模型，并发送设备、应用、性能和使用情况等 SDK 指标。参阅 [ML Kit 条款与隐私](https://developers.google.com/ml-kit/terms)和 [Android 数据披露说明](https://developers.google.com/ml-kit/android-data-disclosure)。

## 备份与日志

本地 ZIP 备份包含正文、阅读记录、图片和非密钥设置。它采用普通 ZIP 格式，请保存在可信位置。

阅读日志由用户主动导出或分享，包含应用版本、系统版本、机型、固定事件码和代码位置。分享前可以自行检查压缩包。
